# Convivial Tool Design

## Methodology
A set of DfODM requirements nspired by Ivan Illich description of convivial technology in [[Tools-for-Conviviality]]. 

Includes:
- [[Repairability]]
- [[Scalability]]
- [[Legibility]]
- [[Modularity]]
- [[Material Honesty]]
- [[Energy Propriety]]
- [[Skill Cultivation]]
- [[Openness]]
- [[Robustness]]
- [[Contextual Fit]]
- [[Autonomy Support]]
- [[Documentedness]]
- [[Fabrication Accessibilty]]
- [[Interoperability]]
- [[Graceful Degredation]]
