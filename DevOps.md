# DevOps

## Core idea
DevOps are practices and tools that automate and integrate the processes between software development (Dev) and IT operations (Ops), such as:

[[Continuous Integration]] (CI): Developers frequently merge code into a central repository, where automated builds and tests are run to catch bugs early.
[[Continuous Delivery]] (CD): Code changes are automatically prepared, tested, and deployed to production or staging environments.

There are more, but I am mostly interested in CI/CD so far.
