# JADAM

## Core idea
- ultra-low-cost organic farming system created in South Korea by Youngsang Cho 
- Jayeon-ul Damun Saramdeul loosely translates to "people who resemble nature"
- if you can [[control aphids]] and [[control powdery mildew]] you can manage pest control
