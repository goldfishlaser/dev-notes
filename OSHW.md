# OSHW

## Core idea

Open Source Hardware (OSHW) refers to physical objects and tangible devices whose design blueprints, schematics, and manufacturing files are made publicly available so anyone can study, modify, build, and sell them. The Open Source Hardware Association provides a definition and certification process for OSHW. 

My project [[DfODM]] is the branch of OET work relating to the development of Open Source Hardware. Its technologies will use [[DOF]] and apply for OSHWA certifications.
