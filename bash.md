# bash

## Core idea
Bash scripting is the process of writing a sequence of commands in a text file to be executed by the Bash (Bourne Again SHell) program. Instead of typing commands one by one into a terminal, a script allows users to automate repetitive tasks, manage systems, and execute complex workflows in a single step.
This skill is part of becoming a better at [[DevOps]].
