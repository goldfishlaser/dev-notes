# behavior driven development

## Core idea
Behavior-Driven Development (BDD) is an agile software process that bridges the gap between business and technical teams. It focuses on defining expected software behavior from the user's perspective using a shared, plain-language format. 

BDD refines [[Test-Driven Development]] (TDD) by putting communication and user experience first.
