# dublin core

## Core idea
simple, standardized way to describe digital resources

 designed for interoperability on the basis of [[Semantic Web]] or [[Linked Data]] principles

 uses Uniform Resource Identifiers (URIs) as global identifiers

 15 elements:
- Creator, 
- Contributor, 
- Publisher, 
- Title, 
- Date, 
- Language, 
- Format, 
 -  Description, 
- Identifier, 
- Relation, 
- Source,
- Type
- Coverage,
- Rights
