# JSON

## Core idea
JSON stands for [[JavaScript]] Object Notation; it is a light, plain-text format used to store and send data. It uses simple key-value pairs and arrays, making it easy for both humans to read and computers to write. Although JavaScript is in the name, it is language-independent.

JSON and [[YAML]] can represent each other because they both map data to the same basic abstract structures: scalars (strings, numbers, booleans, null), maps (objects/dictionaries), and arrays (lists).Because YAML is a superset of JSON, any valid JSON file is automatically valid YAML, while converting YAML to JSON requires stripping out YAML's unique advanced styling and features. This is used in [[YAML datastore]]
