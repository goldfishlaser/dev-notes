# pen plotting

## Core idea
Pen plotting is a computer-controlled mechanical drawing process that uses physical pens and ink to render vector graphics on paper or other flat media

I was briefly volunteering with the Open Source Ecology project to document a process to use D3D Universal 3D Printers as Pen Plotters. This caused me to develop an interest in pen plotting.
