# reticulum

## Core idea
 a secure, cryptography-based networking stack used to build independent, localized, and wide-area mesh networks using everyday hardware like LoRa radios, Wi-Fi, Ethernet, and serial connections. It acts as an alternative to traditional TCP/IP, designed to function seamlessly even over extremely low-bandwidth and high-latency links.
