# yaml

## Core idea
YAML stands for "YAML Ain't Markup Language". It is a simple, human-readable data format used mainly for writing configuration files, storing data, and sharing information between different programming systems.

YAML is chosen for use in [[yaml datastore]] because of its human-readability which makes it great for application to a version control and change tracking system for hardware.
